# A to-do list application

this app is ran on the terminal and it helps the user to have a proper schedule of his/her day.
also helps in proper management one's time An application which creat a todo list.

## Project Goals

. This app was build to help the user save time.
. In the absence of a nor=te book this app can come in   very handy.
. user could add or remove items from the todo-list at any time.

## Tech stack
The main programming language i used is for this appliction is Bash scripting

## 🖥 Features
-Displays a list of task to done
-has a add, option for adding more items to the list
-A delete option to remove task which are already done
-a list option to display a list of task yet to be done on the list
